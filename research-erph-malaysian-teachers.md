# Research: eRPH for Malaysian Teachers

_Research date: 4 October 2026_

## 1. What eRPH is

**eRPH / e-RPH = Rancangan Pengajaran Harian Secara Dalam Talian** (Electronic Daily Lesson Plan) — the digital version of the daily lesson plan (RPH) that Malaysian teachers have traditionally written in the school "buku rekod" (record book).

- RPH is a **legal requirement**: Peraturan 8, Peraturan-Peraturan Pendidikan (Kurikulum Kebangsaan) 1997 under the Education Act 1996 (Akta 550). The record book must be available for inspection by the Ketua Pendaftar.
- Must contain: Profil (mata pelajaran, kelas, tarikh, masa, Standard Kandungan, Standard Pembelajaran), Objektif, Aktiviti PdP, Refleksi (plus EMK/KBAT elements in practice).
- KPM introduced digital/online RPH variants from around 2018 onward; the current **official** channel is via the **DELIMa** platform (Digital Educational Learning Initiative Malaysia).

## 2. Current official policy (2025–)

**Surat Siaran KPM Bilangan 2 Tahun 2025** — "Penyediaan Rancangan Pengajaran Harian Secara Dalam Talian (e-RPH) Melalui Pelantar DELIMa bagi Kegunaan Guru di Sekolah Bawah KPM"
- Ref: KPM.100-1/3/2 Jld.10, dated 23 April 2025, signed by Ketua Pengarah Pendidikan Datuk Azman Adnan.
- Endorsed by Mesyuarat Profesional KPM Bil. 5/2025 (13 February 2025). Effective immediately on issue.
- Accompanied by **Garis Panduan Penyediaan e-RPH KPM (2025)** with 7 flowcharts (Lampiran 1–7) and a FAQ (Soalan Lazim).

Key policy points:

| Point | Detail |
|---|---|
| Voluntary? | **e-RPH is a "kaedah PILIHAN"** — an option, not mandatory. Schools may keep their existing RPH methods (book/fail) as long as the record-book requirements are met. |
| Who | All teachers from prasekolah to menengah atas. |
| Platform | DELIMa (delima.moe-dl.edu.my), using each teacher's **DELIMa ID** (Google Workspace account). |
| Submission | Teachers prepare files and **submit via Google Classroom** ("Join Class e-RPH PENTADBIR"), one file per week named `MINGGU 1-NAMA GURU`. |
| Templates | Google Sheets/Docs "tapak" templates: `bit.ly/erph_prakpm` (prasekolah), `bit.ly/erph_skkpm` (sekolah rendah), `bit.ly/erph_smkpm` (sekolah menengah). |
| Monitoring | Administrators (GB/Pengetua/GPK) check submissions in Classroom grades: **grade = 1** if lengkap, **grade = 0** if tidak lengkap, plus a private comment. |
| Printing | Original FAQ required **weekly printing**; KPM **withdrew that order on 1 May 2025** after teacher feedback (Datuk Azman Adnan). Teachers need not print weekly but must produce RPH on request. |
| Read with | Surat Pekeliling Ikhtisas Bil. 3/1999: Penyediaan Rekod Pengajaran dan Pembelajaran. |

### Roles (Garis Panduan 2025, §3)
1. **Guru** — prepare e-RPH (Lampiran 3–6), choose the Classroom group matching their reviewer (GPK/GB/Penyelia Petang), submit by the school-set weekly deadline, can work **offline** and upload later, save/printable copies, escalate problems to the coordinator.
2. **Guru Penyelaras e-RPH KPM** — brief teachers/admins, set up the Classroom, set submission deadlines, provide first-line technical help, escalate to PPD desk officer (Unit Sumber Teknologi Pendidikan).
3. **Pentadbir Sekolah (Pengetua/Guru Besar)** — appoint the coordinator, encourage use, monitor submissions (Lampiran 7), ensure records are retrievable, train staff.
4. **PPD** — desk officer at Unit Sumber Teknologi Pendidikan; run training; handle district technical issues.
5. **JPN** — desk officer at Sektor Sumber Teknologi Pendidikan; brief coordinators/admins/PPD; monitor compliance; escalate to KPM (Sektor Pelantar Pembelajaran, Bahagian Sumber dan Teknologi Pendidikan).

### Workflow (teacher's weekly loop)
1. Log in to DELIMa → Classroom → join "e-RPH PENTADBIR" class.
2. First time: copy the template for your level via the bit.ly link, rename `MINGGU 1-NAMA GURU`.
3. Later weeks: Class Drive folder → My Drive → File > Make a copy → rename `MINGGU 2-NAMA GURU`.
4. Fill Sheet MENU (teacher/school name, class, time, subject, year, date) → Sheet RPT (subject, class, year/tingkatan, tarikh, SK, SP) → Sheet harian (tema/bidang/tajuk, SK, objektif, aktiviti, refleksi, intervensi).
5. Submit in Classroom ("Add or create" → Google Drive file → **Turn in**) by the deadline.
6. Administrator grades it 1/0 with a private comment; teachers can track status under **Grades** in Classroom.

Official guide links (from Lampiran 5.0):
- `bit.ly/siteerphkpm` — e-RPH KPM guide site (Google Sites: sites.google.com/moe-dl.edu.my/erph-kpmv1)
- `bit.ly/maklumat_erphkpm` — e-RPH info
- `bit.ly/erph_prakpm` / `bit.ly/erph_skkpm` / `bit.ly/erph_smkpm` — templates by level

## 3. Ecosystem / history (what teachers actually encounter)

Several overlapping "eRPH" systems exist, which causes confusion:

1. **eRPH KPM on DELIMa + Google Classroom/Sheets** — the current official system (2025–present).
2. **eRPH KPM v1 (AppSheet)** — earlier MoE Google Sites/AppSheet app (sites.google.com/moe-dl.edu.my/erph-kpmv1, AppSheet app "eRPHKPM"), used for management, monitoring and reporting of RPH; still hosts the guide site.
3. **"RPH Online" / school-built systems** — long-running community systems (e.g., rphonline.teknologihijau.net, "RPH Lite"), with admin/headmaster verification; some schools used AppSheet apps ("eRPH SK", "My ERPH", "eRPH Sekolah Rendah") with folders per teacher.
4. **Third-party/commercial tools** — eRPH Pro (erphpro.com), RPH365, Pandai Teacher (AI lesson-plan generator with KSSR/KSSM templates), RPH Helper (Google Sheets + ChatGPT workflow), MyRPH etc. These generate RPH faster; the teacher still pastes/submits into the official channel.

## 4. Pain points reported by teachers
- Repetition: rewriting similar RPH for every class/subject/week.
- Keeping up with the latest KPM format (DSKP Standard Kandungan/Standard Pembelajaran, EMK, KBAT, PAK21).
- Extra workload on top of teaching; printing directive (April 2025) caused backlash before being withdrawn.
- Fragmentation: multiple systems (DELIMa Classroom, old AppSheet eRPH, school systems) and account/login issues (DELIMa ID, Google Classroom roles).
- Administrator monitoring is manual (checking Classroom grades/comments).

## 5. Why it matters (policy context)
- e-RPH is an initiative under **Teras 5** of the Malaysian Education Blueprint — teacher effectiveness and wellbeing.
- Fits the national digital-education agenda: cloud storage, real-time monitoring, paperless, professional collaboration (sharing RPH banks), administrators gain digital fluency.
- Benefits claimed: no printing/filing, reusable templates with SK/SP pre-filled, access anywhere (laptop/phone), offline drafting, easier GB/Pengetua monitoring, safer record keeping.
